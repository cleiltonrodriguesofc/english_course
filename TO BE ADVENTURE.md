# TO BE ADVENTURE
## Jogo de avaliação pós-aula — Verb To Be

### Objetivo

Criar um jogo de aproximadamente **30 minutos** para uma criança realizar depois da aula sobre o **Verb To Be**.

O jogo deve funcionar como uma grande aventura dividida em fases. Cada fase testa uma parte diferente do conteúdo aprendido.

A criança não deve sentir que está respondendo uma prova. Deve sentir que está avançando por um jogo, desbloqueando lugares, resolvendo missões e chegando ao desafio final.

O jogo deve avaliar:

- Present Simple do Verb To Be;
- Past Simple do Verb To Be;
- Future com `will be`;
- formas afirmativas;
- formas negativas;
- formas interrogativas;
- short answers;
- contractions;
- escolha do verbo a partir do contexto;
- identificação e correção de erros;
- compreensão de pequenas situações;
- capacidade de diferenciar presente, passado e futuro.

---

# ESTRUTURA GERAL

Duração esperada:

**25–35 minutos**

Dividir o jogo em aproximadamente **8 fases**.

Cada fase deve durar entre 3 e 5 minutos.

Fluxo:

**🏠 Home → 🌳 Present Forest → 🤖 Robot Lab → 🏰 Past Castle → 🚀 Future World → ❓ Question Cave → 🧩 Time Machine → 👑 Final Boss → 🏆 Results**

O mapa deve mostrar visualmente o progresso.

Quando uma fase é concluída, o próximo local é desbloqueado.

# ❤️ SISTEMA DE VIDAS

Não utilizar sistema tradicional de vidas.

A criança nunca deve receber:

**GAME OVER**

O objetivo é medir conhecimento, não impedir que termine o teste.

# 🧠 O QUE DEVE SER REGISTRADO

Para cada pergunta, registrar internamente:

- qual conteúdo estava sendo avaliado;
- resposta da criança;
- resposta correta;
- se acertou;
- quantidade de tentativas;
- fase;
- tempo verbal;
- tipo de estrutura: afirmativa, negativa ou interrogativa.

Isso permitirá descobrir padrões.

Por exemplo:

**Present: 95%**

**Past: 65%**

**Future: 90%**

E dentro do Past:

**Affirmative: 90%**

**Negative: 70%**

**Questions: 40%**

Isso é muito mais útil pedagogicamente do que simplesmente dizer que ela tirou 8.

# 🎯 PRINCÍPIO MAIS IMPORTANTE

O jogo deve mudar gradualmente de:

**APRENDER → PRATICAR → RACIOCINAR → SER AVALIADO**

Por isso:

### Fases 1–2
Mais ajuda.

### Fases 3–4
Prática contextualizada.

### Fases 5–6
Mistura dos conhecimentos.

### Fase 7
Pouca ajuda.

### Fase 8
Avaliação praticamente independente.

A criança começa pensando:

**“I → am.”**

Mas deve terminar sendo capaz de perceber sozinha:

**Yesterday → past → they → were**

ou:

**Tomorrow → future → will be**

sem o jogo dizer explicitamente qual regra utilizar.

O objetivo final não é descobrir se a criança decorou `am/is/are/was/were`, mas verificar se consegue **reconhecer o contexto e escolher corretamente a forma do Verb To Be no presente, passado e futuro.**
